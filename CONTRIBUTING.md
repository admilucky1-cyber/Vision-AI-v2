# Contributing to Vision AI

Thank you for your interest in improving Vision AI.

## Ways to Contribute

- Bug reports & feature requests via Issues
- Documentation improvements
- UI / theme polish (regenerative green)
- Free-tier reliability and keep-alive improvements
- Flutter / web Container-Widget client enhancements

## Development Setup

```bash
git clone https://github.com/admilucky1-cyber/Vision-AI-v2.git
cd Vision-AI-v2
cp .env.example .env
pip install -r requirements.txt
python main.py
```

## Guidelines

1. Keep changes focused and small where possible.
2. Do not commit secrets, API keys, or large binary dumps.
3. Prefer free-first, production-ready patterns.
4. Match existing style (Python FastAPI backend, regenerative UI).
5. Update `VERSION` / `versions.json` and CHANGELOG when shipping a release.

## Pull Requests

- Clear title and description
- Link related issues
- Test locally before opening the PR

## Code of Conduct

Be respectful and constructive. Harassment or spam will not be tolerated.
